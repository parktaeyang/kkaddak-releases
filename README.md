# Kkaddak(까딱) 다운로드

Mac 카메라로 손 제스처를 인식해 키 입력으로 바꿔주는 무료 macOS 메뉴바 앱입니다.

- 다운로드 페이지: https://parktaeyang.github.io/kkaddak-releases/
- 최신 버전: [Releases](https://github.com/parktaeyang/kkaddak-releases/releases/latest)
- 소스 코드: https://github.com/parktaeyang/Kkaddak

요구 사항: macOS 13 이상, Apple Silicon(M1 이후), 카메라
